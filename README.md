# Internship Market Scanner

Streamlit-based job discovery tool for collecting, filtering, and reviewing early-career opportunities from multiple online sources.

The project focuses on improving search efficiency through automated data collection, filtering logic, and structured role aggregation workflows.

---

## Overview

The platform aggregates internship and graduate opportunities from multiple sources and presents them through a searchable Streamlit interface.

The project demonstrates:

- Automated data collection workflows
- Structured data cleaning and transformation
- Keyword-based filtering systems
- Streamlit dashboard development
- Lightweight ETL pipeline design
- Workflow automation for recurring job searches

---

## Key Features

- Multi-source job aggregation
- Dynamic and static website scraping support
- Automated data cleaning and standardisation
- Role filtering and categorisation
- Keyword-based relevance scoring
- Streamlit dashboard interface
- CSV export support

## Example Workflow

1. Collect job listings from multiple sources
2. Parse and standardise structured fields
3. Apply filtering and scoring logic
